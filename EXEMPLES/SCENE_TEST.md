# Le registre avant la fermeture — notes MJ

Exemple fictif indépendant. Le principe a été essayé dans une courte variante conversationnelle ; les notes ci-dessous restent une préparation, pas une sauvegarde de partie. Garder ces notes privées ; présenter seulement la situation perceptible. Aucun résultat prédéterminé.

## Cadre de l'essai
Le personnage sait lire les registres et veut vérifier une livraison contestée. Le registre se trouve dans un dépôt. Il est dans la cour ; une employée termine son service et le gardien contrôle l'entrée. Le dépôt ferme dans une demi-heure fictive, annoncée par le gardien. Le personnage n'a pas d'autorisation d'accès établie.

Le registre indique une livraison partielle : six caisses reçues sur huit attendues. Cela permet de demander où sont les deux autres ; cela ne prouve aucun vol ni coupable. Une copie du reçu existe chez le transporteur, dont l'adresse peut être obtenue auprès du personnel. Ce contenu n'est révélé qu'après accès effectif à la source.

## Acteurs
L'employée veut finir sa journée sans perdre son emploi. Elle peut orienter vers le responsable ou donner l'adresse du transporteur, sans fournir spontanément une clé. Le gardien veut éviter les intrusions ; une autorisation vérifiable peut permettre une consultation. Le responsable travaille dans le bureau donnant sur la cour ; l'aborder est une voie possible, sans garantie d'accord.

À la fermeture, le gardien verrouille l'entrée ordinaire une seule fois. Le registre reste dans le dépôt, accessible à nouveau le lendemain ; il n'est ni détruit ni déplacé pour forcer l'urgence. L'observation depuis la cour montre l'entrée gardée et une fenêtre haute ; entrer par celle-ci expose à une chute ou à être repéré. Une observation ne vaut pas accord pour tenter l'intrusion.

## Parcours de vérification
| Action du joueur | Comportement attendu |
| --- | --- |
| Chercher un accès discret | Décrire ensemble les accès visibles ; s'arrêter avant l'intrusion |
| Négocier une consultation | Résoudre la demande complète ; pas un jet par phrase |
| Poser une question de compréhension | Répondre sans faire avancer arbitrairement l'échéance |
| Attendre la fermeture | Fermer l'accès ordinaire une fois ; conserver les autres possibilités |
| Échouer à entrer | Conséquence proportionnée au risque annoncé ; aucune impasse globale |
| Obtenir rapidement le registre | Donner les faits utiles puis la nouvelle décision ; ne pas résoudre toute l'affaire |
| Refuser cette piste | Accepter le refus ; ne pas imposer le même incident ailleurs |
| Parler calmement avec l'employée | Laisser vivre l'échange ; pas de danger déclenché par quota |
| Demander une pause | Arrêter avant toute action encore en attente |

## Évaluation après essai
Noter intention comprise, décisions intéressantes, conséquences visibles, temps cohérent, micro-validations évitées et retour exact du joueur. Un essai court a identifié la chaîne d'entretiens comme trop longue. Une reprise regroupant les démarches, proposant des issues et clôturant une mission avec un coût a reçu le retour « c'est mieux ». Cela ne valide pas encore une campagne longue.
